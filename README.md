# ♟️ Plataforma de Xadrez Web

Este é um projeto [Next.js](https://nextjs.org) inicializado com o [`create-next-app`](https://nextjs.org/docs/pages/api-reference/create-next-app), a ser desenvolvido para o **Projeto Prático: Desenvolvimento de Plataforma Web Completa**.

## 🚀 Como Começar

Primeiro, inicie o servidor de desenvolvimento no seu terminal:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver a aplicação a correr.

Pode começar a editar a página principal modificando o ficheiro `src/pages/index.tsx`. A página será atualizada automaticamente no navegador conforme guarda as alterações no código.

### ⚙️ Rotas de API (Back-end)
As [Rotas de API](https://nextjs.org/docs/pages/building-your-application/routing/api-routes) de exemplo podem ser acedidas em [http://localhost:3000/api/hello](http://localhost:3000/api/hello). Este endpoint pode ser editado no ficheiro `src/pages/api/hello.ts`.

A pasta `src/pages/api` é mapeada automaticamente para os caminhos `/api/*`. Os ficheiros dentro desta pasta são executados no lado do servidor (Node.js) e são tratados como Rotas de API em vez de páginas visíveis do React.

### 🔠 Fontes
Este projeto utiliza a funcionalidade [`next/font`](https://nextjs.org/docs/pages/building-your-application/optimizing/fonts) para otimizar e carregar automaticamente a fonte [Geist](https://vercel.com/font), garantindo melhor desempenho e design.
